Este é um projeto pessoal meu para eu me fortificar e buscar aperfeiçoamento na linguagem PHP. O projeto consiste em buscar os melhores preços de perifericos e componentes de PC para que a pessoa possa se informar qual o melhor custo beneficio e comparar o quão vale a pena comprar aquilo no momento

Por enquanto essa é a estrutura da tabela price_history que é onde guarda o historico de preços dos produtos, temos a coluna "priceId" que é o identificador de preço do produto, o "productId" que é o identificador do próprio produto, "store" que é o nome da loja de onde o produto vem, "value" que é o valor do produto, a "url" do produto que vai redirecionar para o site que o produto esta a venda, "imageUrl" que é a imagem do produto que é pega no site e não colocada na mão, e por fim o "fetchedAt" que é a data e hora em que o preço foi coletado.
